# SIN

Syntax highlighting support for the [SIN](https://sinjs.com) full stack JavaScript framework.

```js
const Div = s`div
  bc hotpink
  p 10
  br 4
  ta center
  ff system-ui
`;

const List = s`ul
 pl 10
 pb 5
 list-style-type none
 ff system-ui
`;

s.redrawing();
s.sleep();
s.with();
s.isAttrs();
s.isServer();
s.pathmode();
s.redraw();
s.mount();
```
